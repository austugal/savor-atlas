# Savor Atlas

An interactive cooking website by Tiago Fitas.

[Visit the live website](https://savor-atlas.pages.dev/)

## Project

Savor Atlas explores cooking, recipe discovery and practical kitchen tools in an interactive website.

This repository is a **portfolio showcase**, not the source checkout for the current Cloudflare deployment. The current production source has not been imported here. The live website remains the place to try the project.

## Feedback

Report a problem with the page URL, browser, steps to reproduce and expected behaviour. Avoid sharing personal information in public issues.
